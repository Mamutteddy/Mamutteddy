## ⚡ Current Mission: Beatnode Protocol
I am building **Beatnode**, a peer-to-peer music distribution protocol on the Bitcoin Lightning Network.

**The Thesis:** Remove the parasites. 
By using P2P sharding and instant Lightning settlements, we allow artists to keep their value and fans to participate in the network.
